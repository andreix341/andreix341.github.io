Lockbit

Type
DFIR
Difficulty
Easy
Focus
Memory forensics

Scenario

You are a Digital Forensics and Incident Response analyst investigating a ransomware attack that affected a company's system. Files have been encrypted and the attackers are demanding payment for decryption. A memory dump of the infected system is provided along with questions about the attack.

xfreerdp /v:<ipaddress> /u:analyst /p:'123' /cert:ignore /dynamic-resolution

Challenge files can be accessed from the terminal. The archive password is infected:

Memory dump (password: infected): /home/analyst/Desktop/ChallengeFile/Lockbit.zip

Task 0

Can you determine the date and time that the device was infected with the malware? (UTC, format: YYYY-MM-DD hh:mm:ss)

Scan the memory dump for running processes with Volatility:

vol.py -f Lockbit.vmem windows.pslist

One process looks suspicious:

900     216     mal.exe 0xfa8018fccb00  267     1254    1       True    2023-04-13 10:06:45.000000 UTC  N/A     Disabled

Answer: 2023-04-13 10:06:45

Task 1

What is the name of the ransomware family responsible for the attack?

Dump files belonging to process 900:

vol.py -f Lockbit.vmem -o dumped/ windows.dumpfiles --pid 900

There will be a large number of dumped files. Calculate the SHA256 hash of the mal.exe.img file:

sha256sum file.0xfa801bfe5320.0xfa801c116990.ImageSectionObject.mal.exe.img

5988e75518b2f365671dc49da18b5a70274351721f1f3a8f8f7bf32984e4024c  file.0xfa801bfe5320.0xfa801c116990.ImageSectionObject.mal.exe.img

Checking the hash on VirusTotal shows these family labels:

Family labels
lockbit
imps
delshad

Answer: lockbit

Task 2

What file extension is appended to encrypted files by the ransomware?

VirusTotal's Behavior tab lists the file-system actions. The following files were written:

C:\Program Files\7-Zip\7-zip.chm.lockbit
C:\Program Files\7-Zip\Lang\ast.txt.lockbit

Answer: .lockbit

Task 3

What is the TLSH (Trend Micro Locality Sensitive Hash) of the ransomware?

The TLSH value can be found in VirusTotal's Details section. An initial attempt using the Volatility 3 dump produced a different sample because dumpfiles handles the image differently. The first value found was:

T18DE3F53DB459D275C88F00B17E2516BAE671F83C037985E3EBD38C299410FE9666AB07

To obtain the expected executable, use Volatility 2:

vol.py -f Lockbit.vmem --profile=Win7SP1x64 procdump --pid=900 --dump-dir=dumped/

Hash the recovered executable and submit it to VirusTotal to obtain the correct TLSH.

Answer: T119E3163DB459E165C8CF04B57E2516BAD671F83C037989F3EBD38C299420EE86626B07

Task 4

Which MITRE ATT&CK technique ID was used by the ransomware to perform privilege escalation?

In VirusTotal's Behavior section, inspect the catalogue tree under Privilege escalation. The entry is:

Modify Existing Service

Malware may modify an existing service to gain persistence. The detailed ATT&CK mapping is Create or Modify System Process: Windows Service (T1543.003).

Answer: T1543

Task 5

What is the SHA256 hash of the ransom note dropped by the malware?

In VirusTotal → Behavior → Files dropped, locate Restore-My-Files.txt. The relevant file is specifically:

C:\Program Files\dotnet\Restore-My-Files.txt

Answer: 67c6784a5296658ac4d633f4e8c0914ecc783b1cf2f6431818c4e2f3cdcce91f

Task 6

What is the name of the registry key edited by the ransomware to apply persistence on the infected system?

In VirusTotal → Behavior → Registry Keys Set, locate:

HKU\S-1-5-21-575823232-3065301323-1442773979-1000\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\XO1XADpO01

Answer: XO1XADpO01
