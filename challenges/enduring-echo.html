Holmes 2025 3: The Enduring Echo

Type
DFIR
Difficulty
Easy
Focus
Windows intrusion analysis

Scenario

LeStrade passes a disk image to Holmes. It is one of the identified breach points and is now showing abnormal CPU activity and anomalies in process logs.

Task 1

What was the first (non cd) command executed by the attacker on the host?

In Security.evtx, search for process creation events by filtering for cmd.exe:

C:\Windows\System32\cmd.exe cmd.exe /Q /c systeminfo 1> \\127.0.0.1\ADMIN$\__1756075857.955773 2>&1

Answer: systeminfo

Task 2

Which parent process (full path) spawned the attacker’s commands?

The parent process is present in the same event row.

Answer: C:\Windows\System32\wbem\WmiPrvSE.exe

Task 3

Which remote-execution tool was most likely used for the attack?

The parent process identified in Task 2 is WmiPrvSE.exe, the Windows WMI Provider Host. This indicates that the attacker executed commands through WMI rather than an interactive shell. The most likely remote-execution tool is Impacket's WMI-based wmiexec.py.

Answer: wmiexec.py

Task 4

What was the attacker’s IP address?

Following the attacker’s commands reveals the address added to the hosts file:

C:\Windows\System32\cmd.exe cmd.exe /Q /c cmd /C "echo 10.129.242.110 NapoleonsBlackPearl.htb >> C:\Windows\System32\drivers\etc\hosts" 1> \\127.0.0.1\ADMIN$\__1756075857.955773 2>&1

Answer: 10.129.242.110

Task 5

The attacker established multiple persistence mechanisms. What is set as the name of the earliest one created?

Further command analysis shows the attacker creating a scheduled task:

C:\Windows\System32\cmd.exe cmd.exe /Q /c schtasks /create /tn "SysHelper Update" /tr "powershell -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\Users\Werni\Appdata\Local\JM.ps1" /sc minute /mo 2 /ru SYSTEM /f 1> \\127.0.0.1\ADMIN$\__1756076432.886685 2>&1

Answer: SysHelper Update

Task 6

Identify the script executed by the persistence mechanism.

The script path is present in the scheduled-task command:

C:\Users\Werni\Appdata\Local\JM.ps1

Answer: C:\Users\Werni\Appdata\Local\JM.ps1

Task 7

What local account did the attacker create?

The PowerShell script initializes a list of usernames, checks whether each exists, and creates a randomly selected user. Security Event ID 4720 records the account creation:

Target: HEISEN-9-WS-6\svc_netupd (S-1-5-21-3871582759-1638593395-315824688-1003)

Answer: svc_netupd

Task 8

What domain name did the attacker use for credential exfiltration?

The attacker added the following host mapping:

C:\Windows\System32\cmd.exe cmd.exe /Q /c cmd /C "echo 10.129.242.110 NapoleonsBlackPearl.htb >> C:\Windows\System32\drivers\etc\hosts" 1> \\127.0.0.1\ADMIN$\__1756075857.955773 2>&1

Answer: NapoleonsBlackPearl.htb

Task 9

What password did the attacker's script generate for the newly created user?

The script builds the password by appending a timestamp to Watson_:

$newUser = Get-Random -InputObject $usernames
$timestamp = (Get-Date).ToString("yyyyMMddHHmmss")
$password = "Watson_$timestamp"

The account-creation time is 2025-08-24 23:05:09, but time shifts prevent using that timestamp directly. Extract the hash with impacket-secretsdump using the SAM, SECURITY, and SYSTEM hives. Then use 20250824 followed by ?d?d?d?d?d?; the ?d mask restricts hashcat to digits.

Answer: Watson_20250824160509

Task 10

What was the IP address of the internal system the attacker pivoted to?

Following the command chain reveals proxy.bat adding a port proxy:

C:\Windows\System32\netsh.exe netsh  interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=9999 connectaddress=192.168.1.101 connectport=22

Answer: 192.168.1.101

Task 11

Which TCP port on the victim was forwarded to enable the pivot?

The listening port is shown in the portproxy command from Task 10.

Answer: 9999

Task 12

What is the full registry path that stores persistent IPv4→IPv4 TCP listener-to-target mappings?

Analyze the SYSTEM hive with a registry viewer and filter for PortProxy:

C:\Users\anrei\Desktop\C\Windows\System32\config\SYSTEM: ROOT\ControlSet001\Services\PortProxy\v4tov4\tcp

Answer: HKLM\SYSTEM\CurrentControlSet\Services\PortProxy\v4tov4\tcp

Task 13

What is the MITRE ATT&CK ID associated with the previous technique used by the attacker to pivot to the internal system?

The attacker used a Command and Control proxy technique to establish the connection to the internal system.

Answer: T1090.001 (Internal Proxy)

Task 14

Before the attack, the administrator configured Windows to capture command line details in the event logs. What command did they run to achieve this?

The command is recorded in the Administrator user's PowerShell history under C:\Users\Administrator\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadline:

reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System\Audit" /v ProcessCreationIncludeCmdLine_Enabled /t REG_DWORD /d 1 /f
